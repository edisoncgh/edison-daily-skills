# Edison Daily Skills

## Content

这个repo用来保存一些我自己日常vibe-coding经常使用的优质skills。

- project-memory：From [edisoncgh/project-memory-skill](https://github.com/edisoncgh/project-memory-skill)，made by 我自己。使用Markdown来维护项目的开发与管理记忆，方便用户随时随地都能使用任何Agent重拾自己的项目开发与维护工作。
- Matt Pocock系列skill：From [mattpocock/skills](https://github.com/mattpocock/skills). 节选了一部分日常vibe coding常用的skill，为了避免重名添加了mp前缀。
- Darwin-skill：花叔开源的skill，用于优化其他skill。
- Neat-Freak：洁癖skill，卡兹克开源的文档同步skill。
- Handoff-driven-development-v2：本人自己制作的，基于项目文档的Agent接力开发skill，用于跨Session/Agent的vibe coding开发场景。

## Use

```bash
npx skills add edisoncgh/edison-daily-skills
```
